# Цветовая палитра

Палитра проекта основана на Bootstrap 5 с переопределёнными в
`src/scss/_variables.scss` значениями. Цвет `info` намеренно удалён из
`$theme-colors` (см. `src/scss/main.scss`).

## Theme colors

Семантические цвета, используемые в кнопках, бейджах, алертах, утилитах
`text-*` / `bg-*` / `border-*` и т.д. Значения берутся из CSS-переменных
Bootstrap (`--bs-*`), поэтому страница автоматически отражает реальные
цвета скомпилированной темы и переключение `data-bs-theme`.

## Subtle / emphasis оттенки

Дополнительные оттенки, которые Bootstrap выводит в `:root` для каждого
theme-цвета. Используются в утилитах `text-*-emphasis`, `bg-*-subtle`,
`border-*-subtle`.
